## 正文

以前收藏了很多视频，但真正回看的并不多。

后来我发现，问题不是内容太少，而是内容没有进入自己的系统。

所以我做了一个本地优先的视频知识库工具：幕库 Muku。

它可以把知识视频或本地音频整理成：

• 原始逐字稿
• 清洗后的可读文本
• 结构化解析稿
• 可放进 Obsidian / RAG 的知识库 Markdown

它的处理方式也比较实在：字幕优先，拿不到字幕时再回退到音频转写；支持批量 URL、JSON 输出和断点续跑。

现在还补了本地引导，第一次使用不用手动编辑一堆配置文件。

macOS / Linux：

```bash
curl -fsSL https://raw.githubusercontent.com/qianzhu18/Muku/main/scripts/install-muku | bash
muku quickstart
```

Windows PowerShell 也有对应安装脚本。

需要说明的是：它是本地优先，不是纯离线。文件、配置和产物默认保存在本地，但转写和 AI 整理会调用你自己配置的 AI 服务。API Key 和 Cookies 都要自己保管。

目前视频主链路支持 B站、YouTube、抖音；小红书等普通网页可以先由浏览器型 AI agent 提取内容，再交给 Muku 整理。

如果你也有一堆“收藏了但没消化”的视频，可以从一条开始。
