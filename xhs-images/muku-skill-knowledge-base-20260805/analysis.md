## Content Understanding

这不是一篇单纯介绍“Skill 是什么”的技术说明，而是一篇从真实使用摩擦出发的工具实测：收藏了很多视频，但内容没有进入自己的知识系统，于是做了 Muku，把视频和本地音频整理成 Markdown 知识资产。

## Target Audience

- **Primary**：想做个人知识库、Obsidian / RAG 或 AI 工作流，但不想先研究复杂配置的人
- **Secondary**：内容创作者、研究者、课程整理者和需要批量处理视频的人

## Hook Analysis

核心钩子不是“又一个 AI 工具”，而是“收藏不等于掌握”。这句话有具体场景，也能自然引出知识沉淀问题。

推荐标题：

1. 我把刷过的视频，变成了自己的知识库
2. 收藏了那么多视频，终于能真正用起来了
3. 一个工具，把视频自动整理成 Markdown

## Value Proposition

1. 视频不再只停留在收藏夹，而是变成可搜索、可连接的 Markdown 文件
2. 字幕优先、音频转写兜底，减少手工整理
3. 一键安装和 `muku quickstart` 降低第一次使用门槛
4. 用户自己管理 API Key、Cookies 和本地产物，边界清晰

## Engagement Design

- **收藏触发**：四类产物、安装命令和适用人群清晰可查
- **评论触发**：读者可以说自己最想整理哪一类视频
- **分享触发**：适合发给正在做 Obsidian、RAG 或课程整理的人

## Visual Direction

采用 Notion 知识卡片风：白色或米白纸张背景、黑灰手绘线条、浅蓝 / 浅黄 / 浅粉强调色，使用流程箭头、文件卡片、简化人物和窗口元素。避免堆叠品牌 Logo，避免“万能 AI”“效率翻倍”等夸张承诺。
