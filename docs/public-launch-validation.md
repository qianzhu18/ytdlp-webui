# Muku 公网宣发前验收记录

验收日期：2026-08-10

## 结论

`1800+` 可以作为首页和宣发的第一视觉锚点，但准确口径是：

> Muku 接入 yt-dlp 的 1800+ 视频解析器生态，重点适配 Bilibili、YouTube、Douyin；实际成功率会受登录态、网络、地区、站点改版和 DRM 影响。

本次环境加载到 1871 个 yt-dlp extractor class，其中 1739 个被 yt-dlp 标记为 working 且不是 Generic。这个结果足以支持“1800+ 解析器生态”，不支持“1800+ 个站全部保证成功”。

## 本次发现并修复

1. 输入文件同时包含重点平台与通用站点时，通用 URL 会被漏掉。现在按每行独立解析、统一去重，混合批量和 `--resume` 已真实复测通过。
2. Docker 默认镜像源返回 403 时，原构建不会切换官方源。现在 APT 与 pip 都会在实际请求失败后回退。

## 宣发前仍需完成

1. **恢复 AI 服务额度并做最后一次真实四产物验收。** 本次本地音频已经进入 OpenRouter 请求，但当前 Key 因总额度限制返回 403，所以“逐字稿 → 清洗稿 → 解析稿 → 知识库稿”的真实在线调用没有在本轮完整结束。自动化测试覆盖了编排逻辑，但不能代替这次最终验收。
2. **把本地版本推送到 GitHub。** 当前公网 `main` 仍是旧版本，README 的新版包装和一键安装脚本尚未全部出现在公网；因此 README 中的 raw GitHub 一键安装地址目前会返回 404。
3. **决定 PyPI 版本口径。** 公网 PyPI 当前是 0.2.2，本地是 0.2.3。若帖子宣传 `muku quickstart`，应先发布 0.2.3；否则暂时只宣传 GitHub 一键安装入口。
4. 推送后重新检查 GitHub 首页、一键安装 URL、CI 徽章与 PyPI 安装。
